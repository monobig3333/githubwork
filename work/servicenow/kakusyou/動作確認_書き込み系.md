## 3. M-1 / M-2 / M-3 イベント転送（em_event）

3 本とも `POST /api/now/table/em_event`。まず M-1 を最小構成で。

```bash
# M-1: 2 スレッド × 2 ループ = 4 イベント
jmeter -n -t M-1/M-1_mid_throughput_normal.jmx -q jmeter.properties \
  -Jthreads=2 -Jramp_up=1 -Jloop.count=2 -Jthroughput=60 \
  -l M-1/runs/smoke_$(date +%Y%m%d_%H%M%S).jtl

# M-2: duration で回るタイプ。10 秒だけ
jmeter -n -t M-2/M-2_mid_throughput_max.jmx -q jmeter.properties \
  -Jthreads=2 -Jramp_up=1 -Jduration.sec=10 -Jthroughput=60 \
  -l M-2/runs/smoke_$(date +%Y%m%d_%H%M%S).jtl

# M-3: 同じく 10 秒
jmeter -n -t M-3/M-3_mid_sustained_load.jmx -q jmeter.properties \
  -Jthreads=2 -Jramp_up=1 -Jduration.sec=10 -Jthroughput=60 \
  -l M-3/runs/smoke_$(date +%Y%m%d_%H%M%S).jtl
```

> M-2 / M-3 は `LoopController.loops=-1` + duration 制御。`-Jduration.sec` を必ず指定すること。
> 指定しないと `jmeter.properties` の 600 / 1800 が効いてスモークにならない。

### 投入されたイベントの確認

```bash
curl -s -H "Authorization: Bearer $TOKEN" \
  "https://$HOST/api/now/table/em_event?sysparm_query=sourceSTARTSWITHmid-test%5EORDERBYDESCsys_created_on&sysparm_fields=source,node,type,severity,sys_created_on&sysparm_limit=20" \
  | jq -r '.result[] | "\(.sys_created_on)  \(.source)  \(.node)  sev=\(.severity)"'
```

`source` の値は JMX のボディ定義に依存するため、0 件なら以下で直近のイベントを見て
