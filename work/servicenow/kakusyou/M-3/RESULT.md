# M-3 MIDサーバ 高負荷継続時の性能飽和確認（30分） 試験結果

## 判定: **OK**（性能飽和なし）

## 試験条件

- 負荷: 50 スレッド / ランプアップ 30 秒 / duration 1,800 秒（30 分）
- 流量制御: Constant Throughput Timer 3,000/分（= 50 件/秒）
- リクエスト: `POST /api/now/table/em_event`（`source=mid-test-M-3`）
- コマンド: `-Jthreads=50 -Jramp_up=30 -Jduration.sec=1800`

## 末尾 50 件の 401 について

実行終了の直前 1 秒間に **HTTP 401 が 50 件**（= スレッド数ちょうど）発生した。

**原因は OAuth アクセストークンの有効期限（1,800 秒 = 30 分）**で、M-3 の実行時間と一致する。
JMeter の setUp Thread Group はテスト開始時に 1 回だけトークンを取得するため、最後の 1 秒で
失効し、実行中だった 50 スレッド分が 401 になった。**転送性能とは無関係な試験ハーネスの制約**である。

投入成功数 89,892 件と ServiceNow 受信数 89,892 件は完全に一致しており、
**成功した投入に対する転送漏れはゼロ**。

次回以降の対策として、duration を 1,740 秒にするか、テスト中のトークン再取得を組み込む。
